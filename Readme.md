## Tech Stack

- **React 18** — Component-based UI
- **Vite** — Fast build tooling
- **React Router** — Client-side routing
- **EmailJS** — Contact form email delivery
- **Boxicons** — Icon library
- **GitHub Pages** — Deployment (via `gh-pages` package)

## Project Structure

```
src/
├── components/    # Reusable UI components (Header, Footer, BackButton)
├── sections/      # Homepage section components (Hero, About, Skills, Contact, etc.)
├── pages/         # Route-level page components
├── hooks/         # Custom React hooks
├── data/          # Shared project data
├── utils/         # Constants and helpers
├── styles/        # Global CSS and page-specific styles
├── App.jsx        # Route definitions
└── main.jsx       # Entry point
```

## Development

```bash
npm install        # Install dependencies
npm run dev        # Start dev server
npm run build      # Production build
npm run deploy     # Build + deploy to GitHub Pages
```
